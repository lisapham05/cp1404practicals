## Code Reviews

### What have you learned from being reviewed by other people?

The feedback I received highlighted areas where my variable names were ambiguous or my logic was too convoluted. 
It also exposed me to alternative—and often more efficient—ways of solving the same problem, 
which broadened my own problem-solving toolkit.

### What have you learned from doing code reviews of other people?

It trained me to read code with a critical eye for quality, looking for things like "magic numbers," 
repeated code, and adherence to style guides, which in turn has made my own code cleaner and more maintainable.
